# Bajaj Dominar 250 — 3D assembly simulator

Browser workshop for a schematic Dominar 250. Orbit, explode, pick parts, enforce install order, run a 50-step teardown / rebuild.

This is **not** a factory CAD dump. Meshes are primitives scaled to published specs. OEM part numbers are not shown because the official fiche was not in the workspace.

```
npm install
npm run dev
```

Controls: drag orbit, scroll zoom, right-drag pan, click select, double-click remove/fit, Ctrl+Z undo, keys 1-6 views, E explode, B empty bay.
